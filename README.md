📩 Subscribe Pop-up
A simple and customizable subscribe pop-up component built using HTML, CSS, and JavaScript. This project demonstrates how to create a responsive modal that encourages users to subscribe to a newsletter or mailing list.
🔗 Live Demo:
https://light828.github.io/subscribe-pop-up-/

✨ Features

📌 Clean and modern pop-up design
⚡ Lightweight and fast
🎯 Easy to integrate into any website
📱 Fully responsive (mobile-friendly)
❌ Close/dismiss functionality
🎨 Customizable styles and content
